# Generated Sample Programs

These are example programs generated by `generate_complex.py` to demonstrate the output quality.

All programs:
- ✅ Compile successfully (100% success rate)
- ✅ Run and produce output
- ✅ Include print statements for observability
- ✅ Are ~50 lines of valid Kotlin code
- ✅ Include functions, variables, control flow, and collections

## Samples

- `sample_0.kt` - Program with String and Double operations
- `sample_1.kt` - Program with Int and Boolean logic
- `sample_2.kt` - Program with mixed types and when expressions

These samples demonstrate the variety and quality of code produced by the template-based generator, suitable for testing Kotlin Native compiler backends.

## Regenerating Samples

To generate new samples:

```bash
python3 ../../generate_complex.py -o sample.kt -n 3 --validate
```
